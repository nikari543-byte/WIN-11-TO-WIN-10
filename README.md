# WIN-11-TO-WIN-10

PowerShell скрипт для безопасного даунгрейда с Windows 11 на Windows 10 с сохранением личных файлов и приложений через спуфинг реестра.

## ️ ВАЖНЫЕ ПРЕДУПРЕЖДЕНИЯ

**Используйте на свой страх и риск!** Этот скрипт модифицирует системные образы Windows.

- **Не гарантируется сохранение данных** — кнопка "Сохранить личные файлы" может остаться серой
- **Возможны проблемы с совместимостью** — AppX-пакеты Windows 11 не работают на Windows 10
- **Тестируйте на виртуальной машине** перед использованием на реальной системе
- **Создайте полный бэкап** системы перед запуском

## 📋 Требования

- Windows 10 или Windows 11 (x64)
- PowerShell 5.1+
- Запуск от имени **Администратора**
- Образ Windows 10 (install.wim или install.esd)

## 🚀 Быстрый старт

### Базовое использование:
```powershell
# Запуск от администратора
.\Patch-Win10Downgrade.ps1 -WimPath "C:\path\to\install.wim"
